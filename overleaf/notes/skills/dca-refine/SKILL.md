# DCA 初稿完善

定位含 CLAUDE.md 与 overleaf/main.tex 的仓库根目录。下列路径以根目录为基准。

1. 读当前状态和 overleaf/notes/prompts/gptpro-draft-review-prompt.md。以 overleaf/main.tex 及引用文件为活动正文，对照 7 月汇报、8 月讨论和 10 月会话。
2. 重建成果之间的联系。对应主张、定理标签、证明与函数类，区分已核对结果、未完成证明和历史设想。
3. 判断证书是否带来新的可证明能力；核对蕴含方向、参数顺序、分解依赖、witness 可达性与可计算费用。
4. 核对复杂度计数、随机输出和下界量词。发现问题时给出适用范围或最小修复，不扩展成无关研究计划。
5. 按已授权范围实施修订。全文重写时先统一主问题与核心定理，再处理标题、摘要、引言、章节衔接和结论。局部任务只处理相关依赖。
6. 英文术语和固定表达参照已读原文并记录出处。不得补造作者、资助、实验或证明结果。
7. 对实际变更进行必要验证，交付变更、证据和未解决问题，更新 PROJECT_STATUS.md。历史审阅状态须先映射到当前版本。

需深化研究判断时按需读 Booming 或 Sparkling，不强制固定轮数或额外代理。证据支持现有内容时直接保留。目标期刊为 MP 或 JMLR，不预设投稿顺序，不把历史助手建议当成期刊要求。
