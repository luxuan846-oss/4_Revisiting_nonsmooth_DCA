## 一、Q2 可以加强：负侧精确，不增加查询阶数

### 加强后的主定理

在你们规定的函数类中，对任意 \(\delta>0,\varepsilon>0\)，确定性算法能够显式输出 \(x,u,v\)，满足

\[
\boxed{
\Psi_\phi(x,u)\leq\delta,\qquad
v\in\partial g(x),\qquad
\|u-v\|\leq\varepsilon,
}
\]

总查询成本为

\[
\boxed{
O\!\left(
\left(1+\frac{\Delta}{\delta}\right)
\left(1+\frac{B^2}{\varepsilon^2}\right)
\right).
}
\]

在 \(\delta\leq\Delta\)、\(\varepsilon\leq B\) 时，它就是

\[
O\!\left(\frac{\Delta B^2}{\delta\varepsilon^2}\right).
\]

因此，**Q2.3 中消除负侧容差所付出的额外 \(\varepsilon^{-1}\) 可以去掉。**

结合下面核对通过的下界，在固定函数类 \(\mathcal D(1,1,1)\) 上，

\[
\boxed{
(\varepsilon^2,0,\varepsilon)\text{-VAC}
\quad\text{的确定性查询复杂度为}\quad
\Theta(\varepsilon^{-4}).
}
\]

上界只使用普通成对分量 oracle。下界即使允许返回两个完整次微分仍成立。这里的最优性针对固定分量界、固定初始差距和上述精度尺度，不包含全部参数的最优依赖。

### 为什么原来的额外因子可以去掉

沿用你们的记号：

\[
M(w)=\phi(w)-\langle v,w\rangle
+\frac{\|w-x\|^2}{2\eta},
\qquad
z=\operatorname*{argmin}_{w}M(w),
\qquad
u_*=v-\frac{z-x}{\eta}.
\]

令实际内层输出为 \(y\)，误差为 \(e=M(y)-M(z)\)。除了任务中已有的恒等式，还能得到

\[
\boxed{
\begin{aligned}
&\Psi_\phi(x,u_*)+\Psi_g(y,v)
+\frac{\eta}{2}\|u_*-v\|^2
+\frac{\|y-x\|^2}{2\eta}\\
&\hspace{3em}=F(x)-F(y)+e.
\end{aligned}
}
\]

**这条等式直接控制旧点 \(x\) 的正侧间隙。**

因此，无须再使用

\[
\Psi_\phi(x,u_*)\leq 2G_\phi\|x-z\|
\]

作线性运输估计。原先多出的 \(\varepsilon^{-1}\)，就来自这个较松的估计。

选择观测下降最小的一步，在旧点输出，取

\[
\eta=\frac{\delta}{\varepsilon^2},
\qquad
\sigma=\frac{\delta}{4},
\qquad
K=\max\left\{1,\left\lceil\frac{4\Delta}{\delta}\right\rceil\right\},
\]

便得到负侧精确的证书。

### 见证也能显式输出

上面的 \(u_*\) 使用未知精确解 \(z\)，只适合作分析。但这个缺口也能补齐。

对内层查询到的次梯度 \(a_j\in\partial\phi(w_j)\) 作加权平均：

\[
u=\sum_{j=1}^{J}\lambda_j a_j,
\qquad
\lambda_j=\frac{2j}{J(J+1)}.
\]

令

\[
S=\sum_{j=1}^{J}\lambda_j
\bigl(\langle a_j,w_j\rangle-\phi(w_j)\bigr).
\]

由共轭函数的凸性，

\[
\phi^*(u)\leq S.
\]

所以算法能计算

\[
\widehat{\Psi}_\phi(x,u)
=\phi(x)+S-\langle u,x\rangle
\geq\Psi_\phi(x,u).
\]

报告给出的加权次梯度内层算法，能够在

\[
O\!\left(1+\frac{\eta B^2}{\sigma}\right)
\]

次查询后控制这个可计算证书。**不需要精确近端调用，不需要计算 Fenchel 共轭，也不只是证明某个不可见的 \(u\) 存在。**

这使主结果比“统一三项误差”更明确：**正侧值误差是必要松弛；负侧值误差可以为零；完整证书仍有匹配的基本查询复杂度。**

## 二、有界分量下界通过核对，但必须使用成对证明

Li–Pan 提供的是弱凸目标的困难函数、完整次微分隐藏层性质和一般确定性算法的旋转论证。它们本身还没有直接给出你们更强信息接口下的下界。citeturn980116view0

你们的有界凸化路线能够完成所需连接。

首先，原实例的最大值表示中，固定权重后，每个坐标的负曲率确实由

\[
-\frac{a_m}{8}q''\!\left(\frac{Nt}{4}\right),
\qquad 0\leq a_m\leq1,
\]

产生。原文也明确给出了 \(3/4\) 的弱凸参数。citeturn318661view3

任务中的凸化函数满足

\[
c_N''(t)
=\frac18\left[q''\!\left(\frac{Nt}{4}\right)\right]_+
\quad\text{几乎处处},
\]

所以它覆盖了全部所需负曲率。固定权重后的分支加上凸化项均为凸函数，再取最大值仍凸。**这里需要把“处处二阶导数”修正为“几乎处处”；\(c_N\) 是 \(C^{1,1}\)，不必是 \(C^2\)。**

其次，

\[
\operatorname{Lip}(C_N)
\leq\frac34\sqrt{\frac{M}{N}},
\qquad
c_N'(0)=0.
\]

前者保证分量界不随精度增长。后者保证：若查询点只使用已显露坐标，新增凸化梯度也只使用这些坐标。因此，两套完整次微分仍然满足逐层显露性质。

最后，报告补出了成对抵抗 oracle 的完整版本：新方向与全部历史查询正交；最终得到一个固定旋转后的函数对；此前返回的两个函数值与两个完整次微分都与这个固定函数对一致。未查询的最终输出作为额外一次查询处理。

**这支持固定分量界下的 \(\Omega(\varepsilon^{-4})\) 下界。**

但当前仓库的 `appendix/lowerbound.tex` 仍是公共二次项的旧归约。它没有全局有界分量，也没有这里的四次下界。需要替换正式证明，不能只更换定理名称。fileciteturn9file0L2-L2

## 三、\(F_0\) 成立，但新颖性应准确归属

### 一维结论还能加强

在一维，可以构造同一个规范分解 \(F=\Phi-\Gamma\)，使所有点同时满足

\[
\boxed{
\partial\Phi(x)-\partial\Gamma(x)=\partial_C F(x).
}
\]

并且能够分别保持原分量界：

\[
\operatorname{Lip}(\Phi)\leq G_\phi,
\qquad
\operatorname{Lip}(\Gamma)\leq G_g.
\]

所以不需要写“常数倍”。

证明采用分布二阶导数的 Jordan 分解：

\[
D^2F=\mu^+-\mu^-.
\]

正负部分不会在同一点同时产生原子。因此，两个凸分量的导数至多一个在该点跳跃，差集恰好等于左右导数构成的 Clarke 区间。连续变差和奇异连续变差也包含在这个论证中。

### 二维可加强为固定半径的 Goldstein 分离

令

\[
F(x)=F_0(x)+3\max\{\|x\|-1,0\}.
\]

这个函数属于 \(\mathcal D(4,1,1)\)。对它的任意有限凸分解，原点都满足

\[
\partial\phi(0)\cap\partial g(0)\neq\varnothing.
\]

但对每个 \(0<r<1\)，

\[
\boxed{
\operatorname{dist}\!\left(
0,\operatorname{conv}
\bigcup_{\|y\|\leq r}\partial_CF(y)
\right)
=\frac1{\sqrt2}.
}
\]

因此，**即使证书误差完全为零、即使允许重新分解，原目标的 Goldstein 残差仍可保持固定正值。**

算法层面的准确量词是：

> 对每个分解，都存在合法的次梯度选择，使精确 DCA 保持在原点；该点沿 \(-e_1\) 的方向导数为 \(-1\)。

不能加强成“每种次梯度选择都会如此”。

### 为什么不能把它宣称为新几何原理

令

\[
T=\operatorname{conv}\{0,e_1,e_2\}.
\]

则 \(F_0=\sigma_T-\sigma_{-T}\)。经典极小对理论给出：

1. 任意等价凸集对都包含一个极小对。
2. 平面中的极小对在共同平移意义下唯一。
3. 多边形的相应边条件保证 \((T,-T)\) 是极小对。

所以任意表示中的 \(A=\partial\phi(0)\)、\(B=\partial g(0)\)，都分别包含 \(T+c\)、\(-T+c\)，从而共享点 \(c\)。这些结论可以在 Grzybowski–Urbański 的 Theorems 7.1、7.2、7.4 中定位。citeturn898352view2

**已确认的是：核心几何机制属于已有理论的直接推论。** 本次没有找到前文以完全相同的“不可消除伪 DC 临界与一维—二维门槛”语言陈述它。论文可以突出这个优化解释和定量分离，同时明确引用几何来源。

## 五、W1–W4 的评估与排序

**W1：保留，但应写成有经典来源的优化分离。** 数学成立。对 DCA 和机器学习优化读者，“所有分解都无法排除该伪临界点”具有解释价值；对极小对理论读者，核心机制已有。最有效的加强是本次得到的三个结果：一维全次微分还原、原分量界保持、二维固定半径 Goldstein 分离。支撑材料已经具备。

**W2：作为机制解释保留，不承担主要新意。** 精确 DCA 新点的正侧 gap 为零，这个批评已经公开；双 Bregman 下降分解也有先例。更值得写入本稿的认识是：同一条下降恒等式支持旧点认证，使负侧保持精确而不增加查询阶数。不要把“负侧运输误差重要”扩张为“所有有效判据都必须松弛负侧”。citeturn109026view1turn528227view4

**W3：保留为研究假设。** 当前没有普通分量 oracle 下 L1 指数困难的证明。仓库 Q3 任务还提出了 L1 可达的正面路线，因此不能提前认定确定性障碍位于 L0 与 L1 之间。需要同一个函数类、同一个接口下的可达性分离，才能把“跨点配对解释确定性”升级为科学结论。fileciteturn10file0L2-L2

**W4：作为已有背景，不作为新发现。** Kong–Lewis 已用非凸模控制确定性成本；Tian–So 的 Proposition 4 进一步给出了该参数依赖的紧性。你们可继续研究的增量，是普通分量信息与方向一致信息之间的转换成本。当前不能声称确定性难度已被负侧凹结构完整刻画。citeturn898352view6turn318661view6

\[

\]

但 W3 仍是猜想。**按当前可形成论文主结果的支撑度，加强后的 Q2 应排在最前。**

## 六、修正后的全文主线与引言钩子

**全文主线：**

> 在分量全局 Lipschitz 的 DC 类上，同点精确次微分残差没有统一有限查询保证；仅松弛正侧支撑值误差，即可用最优 \(\Theta(\varepsilon^{-4})\) 次确定性基本查询显式产生 \((\varepsilon^2,0,\varepsilon)\)-VAC，而一维可还原、二维起可能不可还原的临界结构，刻画了这种可计算证书与原目标 Goldstein 驻点之间的差距。

> 即使允许重新选择任意凸分解，DC 临界性仍可能接受一个沿某方向严格下降、并与 Goldstein 驻点保持固定距离的点。一维中，Jordan 分解能够同时消除全部这类失真；二维中，经典极小对理论已经允许不可消除的例子。因此，研究 DC 算法需要同时回答两个问题：有限一阶信息能够认证什么，以及该证书对原目标究竟保证什么。
